## Slice D — FormField + PageHeader (`src/components/molecules/FormField/`, `src/components/molecules/PageHeader/`)
- **FormField**: `label`, `htmlFor?` (auto id via `useId` when the child has none), `hint?`, `error?`, `required?` (visible "*" + sr "required"), `optional?` label, `counter?: { value, max }`, `layout` "vertical" | "horizontal" (label column, collapses ≤ 640px), `children` = one control. Inject `id`, `aria-describedby` (hint + error ids), `aria-invalid`, `aria-required` into the child via `cloneElement` **only** when the child does not already set them; also export a `useFormField()` context hook so custom controls can read the ids. Error has `role="alert"` only when it changes after mount (avoid announcing on load).
- **PageHeader** (Zone 3): `title` (renders `h1` by default, `titleAs` override), `description?`, `breadcrumb?` (ReactNode — usually `<Breadcrumb>`), `status?` (ReactNode, e.g. Badge), `meta?` (ReactNode row), `primaryAction?` (ReactNode), `secondaryActions?: { label, onClick?, href?, icon?, disabled? }[]` — render first N (`maxVisibleActions`, default 2) as outlined Buttons, overflow into a `DropdownMenu` "More actions"; at ≤ 640px all secondaries collapse into the menu. `tabs?` slot rendered under the header. Exactly one primary.

## Slice E — FilterBar + DataTable (`src/components/molecules/FilterBar/`, `src/components/molecules/DataTable/`)
- **FilterBar**: controlled `value: { search?: string; filters: Record<string, string | string[]> }`, `onChange`; `filters: { id, label, type: "select" | "multi", options }[]`; `searchPlaceholder`; renders InputSearch + filter controls (Select / Combobox multiple), **active filter chips** (Badge with dismiss) + "Clear all", `resultCount?` announced via polite live region, `extra?` slot (right side, e.g. view toggle), `moreFilters?` collapse into a Popover when > `maxInlineFilters` (default 3) or at ≤ 768px. Debounce search internally (`searchDebounceMs`, default 250, implemented locally).
- **DataTable**: composes `Table` + `FilterBar` + `Pagination` + `EmptyState`/`ErrorState` + `Skeleton`. Props: `columns`, `data`, `rowKey`, `loading?`, `error?: { title?, description?, onRetry? }`, `emptyState?`, `filterBar?` (FilterBar props) , `pagination?: { page, pageSize, total, onPageChange, onPageSizeChange }` (server-side) or client mode when omitted, `selectable?` + `bulkActions?: { label, onClick(selectedRows), variant? }[]` rendered in a **bulk action bar** that appears on selection ("3 selected · Clear"), `columnVisibility?` (menu to toggle columns, persisted via callback `onColumnVisibilityChange`), `exportCsv?: boolean | { filename }` (client-side CSV of visible columns; escape `"`, `,`, newlines; guard formula injection by prefixing `=+-@` cells with `'`), `toolbarRight?`, `caption` (required for a11y, can be visually hidden). Read `src/components/molecules/Table/` fully first and pass through its props instead of duplicating features.

## Slice F — Tooltip (generic) (`src/components/molecules/Tooltip/`)
- Generic `Tooltip` that wraps **any** focusable trigger (`children` single element, cloned to add handlers + `aria-describedby`): `content`, `side` "top" | "right" | "bottom" | "left", `align` "start" | "center" | "end", `delay` (default 300), `closeDelay` (100), `open?` / `defaultOpen?` / `onOpenChange?`, `disabled?`, `maxWidth`, `variant` "dark" | "light". Opens on hover **and** focus, closes on Escape / blur / pointer leave; hoverable content (WCAG 1.4.13: dismissable, hoverable, persistent); collision flip to opposite side when out of viewport; portal to body; `role="tooltip"`; reduced-motion aware. Do **not** change the existing `src/components/atoms/ToolTip/` (icon helper); document in the story how they differ. Export name `Tooltip` (+ `TooltipProps`).
