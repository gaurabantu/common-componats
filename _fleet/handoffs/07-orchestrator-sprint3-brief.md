## Slice G — DateRangePicker + NumberInput
- **DateRangePicker** (`src/components/molecules/DateRangePicker/`): reuse the existing calendar stack — read `src/components/molecules/Calendar/` and `src/components/atoms/DatePicker/` first (project depends on `react-day-picker` v9). Props: `value?: { from?: Date; to?: Date }`, `defaultValue?`, `onChange`, `presets?: { label, range: () => {from,to} }[]` (provide `DEFAULT_RANGE_PRESETS`: Today, Last 7 days, Last 30 days, This month, This quarter, Year to date), `min?`, `max?`, `numberOfMonths` (default 2, 1 at ≤ 640px), `label`, `placeholder`, `format?: (d) => string` (default `Intl.DateTimeFormat` with `locale` prop), `clearable`, `disabled`, `error?`. Trigger is a button showing the formatted range; popover dialog with focus management; keyboard per APG date grid; announces selected range.
- **NumberInput** (`src/components/atoms/NumberInput/`): `value?: number | null`, `defaultValue?`, `onChange(value: number | null)`, `min`, `max`, `step` (default 1), `precision?`, `locale?`, `formatOptions?: Intl.NumberFormatOptions` (currency / percent / compact), `prefix?` / `suffix?` slots, `showSteppers` (default true; buttons with aria-labels, press-and-hold repeat), `allowNegative`, `clampOnBlur` (default true), `label`, `error?`, `size`, `disabled`, `readOnly`. Input `type="text"` + `inputMode="decimal"`, role `spinbutton` semantics (`aria-valuenow/min/max/text`), ArrowUp/Down ±step, Shift ×10, PageUp/Down, Home/End to min/max. Parse locale-formatted input (grouping and decimal separators via `Intl.NumberFormat#formatToParts`). Put parse/format in `NumberInput.utils.ts` with thorough unit tests.

## Slice H — SegmentedControl + Wizard
- **SegmentedControl** (`src/components/molecules/SegmentedControl/`): single-choice toggle group. `options: { value, label, icon?, disabled? }[]`, `value` / `defaultValue` / `onValueChange`, `size` "sm" | "md" (heights ≥ 36 / 40px — do **not** reuse the 22px small segmented Tabs), `fullWidth`, `ariaLabel` (required). Semantics: `role="radiogroup"` with `role="radio"` + `aria-checked`, roving tabindex, arrow keys move **and** select, Home/End. Sliding indicator honours reduced motion; forced-colors outline on the selected item.
- **Wizard** (`src/components/molecules/Wizard/`): composes `Stepper` (read `src/components/molecules/Stepper/`) + content + footer actions. `steps: { id, title, description?, optional?, content: ReactNode, validate?: () => boolean | string | Promise<boolean | string> }[]`, `activeStep?` / `defaultActiveStep?` / `onStepChange`, `onComplete`, `linear` (default true), `showReview?` (auto review step listing step titles with "Edit" links), labels (`backLabel`, `nextLabel`, `finishLabel`), `loading?` on finish. Validation failure shows an `Alert` (live assertive) and focuses the step heading; moving steps moves focus to the new step heading. One primary button (Next/Finish).

## Slice I — CommandPalette + Kbd
- **Kbd** (`src/components/atoms/Kbd/`): `<kbd>` styled chip; `keys?: string[]` renders combos with separators; platform-aware `mod` → ⌘ on macOS, Ctrl elsewhere (SSR-safe).
- **CommandPalette** (`src/components/molecules/CommandPalette/`): modal dialog opened with ⌘K / Ctrl+K (`hotkey` prop, `enableHotkey` default true) or controlled `open` / `onOpenChange`. `groups: { id, label, items: { id, label, description?, icon?, shortcut?: string[], keywords?: string[], onSelect, disabled? }[] }[]`, `placeholder`, `emptyState?`, `onSearch?` (async remote results with `loading`), `recent?` group. Combobox pattern: input `role="combobox"` + `aria-controls` listbox, `aria-activedescendant`, ArrowUp/Down/Home/End, Enter selects, Escape closes, focus restored to the previously focused element. Fuzzy-ish ranking in `CommandPalette.utils.ts` (prefix > word-start > substring; keywords count) with unit tests. Portal, focus trap, scroll lock (reuse `src/components/molecules/Modal/bodyScrollLock.ts`), full-screen at ≤ 480px.
